# video_montage

Производство видеоконтента: от новости до готового ролика. Публичный репозиторий-фреймворк.

## Части

| Каталог | Что делает | Статус |
|---|---|---|
| [`newsroom`](./newsroom) | Редакция: 40 источников → отбор десятки → эфирный лист к утру. Смыслы формата, тон, ритуал записи. | В бою, крон каждое утро |
| [`mcp-montage`](./mcp-montage) | Фабрика монтажа: исходники → транскрипт → монтажный план → сегменты → master. Три фазы, два человеческих гейта. | Прогнан на пилотном ролике |

## Как это связано

```
newsroom            съёмка            mcp-montage
эфирный лист   →   исходники    →   транскрипт → план → сегменты → master
(что говорить)     (raw/)            (два гейта: монтажное решение и картинка)
```

Редакция отвечает на вопрос «о чём сегодня говорить», фабрика — «как это собрать в ролик».
Стык описан в [`newsroom/edit/REFERENCES.md`](./newsroom/edit/REFERENCES.md).

## Красные линии

- Ничего не публикуется автоматически. Публикация — всегда решение автора.
- Тяжёлые исходники и мастера в git не попадают.
- Гейт нельзя пройти по факту существования файла — нужен осознанный апрув.
