# Локальная B-roll библиотека

Эта папка заменяет внешний сервис хранения футажей на первом этапе.

```text
broll/
  originals/   неизменяемые мастер-файлы
  proxies/     лёгкие копии для просмотра и анализа
  thumbs/      thumbnails/contact sheets
  catalog.json индекс библиотеки
```

Добавление ассета считается завершённым, когда есть оригинал, стабильный ID и запись в `catalog.json`. До проверки прав поле `rights.status` должно оставаться `unknown`.
