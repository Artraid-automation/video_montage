# Decision policy (агент решает сам)

Наблюдатель не выбирает техничку. Агент:

1. Выбирает путь/имя/порядок атомов
2. Пишет решение + краткое «почему» в run-лог или experiment
3. Действует
4. Если провал — меняет подход и пишет Verdict

## Когда всё же спросить наблюдателя

- удаление медиа / проекта
- финальный publish
- креатив: «какой смысл/тон важнее»
- этика/права: чужой контент в референсе

## Решения по умолчанию (v0)

| Тема | Решение | Почему |
|------|---------|--------|
| Knowledge base | `lab/` в корне | ASCII, не мешает медиа |
| Стиль | сначала analysis референса, потом presets | не выдумывать шрифты |
| Субтитры | локальный whisper при первом captions-прогоне | Free, без Studio |
| Переходы | маркеры + ручной fallback в v0 | API Free слаб на transitions |
| Пути tooling | критичные скрипты под `E:\davinci-resolve-mcp` | кириллица ломала MCP config |
| Первый билд | plan → короткий взгляд наблюдателя → build | без сюрпризов на таймлайне |
