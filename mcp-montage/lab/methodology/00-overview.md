# Обзор методологии

## Цель

Не «идеальное видео с первого раза», а воспроизводимая система:

- референс → стиль-пресет
- исходники → черновик рилса (обрезка, субтитры, базовые эффекты)
- наблюдатель → правки вкуса
- агент → запись уроков → следующий прогон быстрее

Целевая доля агента: **~80% рутины**. 20% — вкус, смысл, финальный монтажный жест.

## Два слоя методики

### 1. Монтаж / продукт

Что должно получиться как видео: хук, ритм, субтитры, B-roll, цвет, звук, экспорт 9:16.

### 2. MCP-монтаж / процесс

Как агент делает это через Cursor + CursorBridge + Resolve Free:

- сначала читать статус проекта
- деструктивные операции — только с явным ок наблюдателя
- после каждого нового приёма — атомарная инструкция
- пресеты живут в файлах `lab/`, не только в голове чата

## Жизненный цикл одного рилса

```
REF    разобрать референс → style pack
SRC    проиндексировать исходники → source-map
PLAN   план таймлайна (без Resolve) → runs/NNNN-plan.md
BUILD  атомы в Resolve (bridge on) → черновик
REVIEW наблюдатель смотрит экспорт
LEARN  записать atoms / experiments / обновить pipeline
```

## Hard rules

1. **Нет bridge — нет правок в Resolve.** Сначала `Workspace → Scripts → CursorBridge`.
2. **Нет записи — действие не считается завершённым.**
3. **Референс не копируем пиксель-в-пиксель** — копируем систему (ритм, иерархия текста, палитра, типы переходов).
4. **Free Resolve limits** учитываем: transitions/keyframes частично руками; AI-студийные фичи → локальные замены (whisper/demucs/rembg) когда дойдём.
5. **Кириллица в путях** — риск для скриптов; для tooling предпочитать ASCII (`lab/`, `E:\davinci-resolve-mcp`).
