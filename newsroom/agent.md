# agent.md — устройство проекта «Личный бренд»
Актуально на 23.08.2026.

## Что здесь есть
```
brand/     смыслы: VISION (зачем), FORMATS (что снимаем), VOICE (как говорим)
ritual/    MORNING (утренний протокол), LOG (журнал записей — цепочка привычки)
feed/      SOURCES.md (реестр, человеческий) + feeds.txt (машинный) + TASTE.md (калибровка)
           digest/    утренние дайджесты YYYY-MM-DD.md — то, что читается с пробкой
scripts/   morning.sh   — весь утренний прогон одной командой (крон 6:30, страховка 8:15)
           net.py       — забор страниц через два выхода: этот сервер и российский crm
           collect.py   — обход реестра -> feed/cache/candidates-<дата>.json
           select.py    — отбор десятки -> feed/cache/selected-<дата>.json
           extract.py   — ключевые абзацы -> feed/digest/<дата>.json
           render.py    — вёрстка листа из json + самодостаточная версия для телефона
           template.html — вёрстка эфирного листа (единственное место, где правится вид)
           unwrap.py    — разворот ссылок агрегатора в адрес оригинала
           llm.py       — изолированный вызов модели
           check_feeds.sh — проверка живости источников
           standalone.py  — обернуть готовый фрагмент в самодостаточный файл (разовая утилита)
topics/    BANK.md — копилка тем для длинных роликов
raw/       исходники с камеры, по датам
edit/      REFERENCES.md — референсы монтажа и требования к автомонтажу
```

## Неочевидное
- **Проект автомонтажа на этом сервере отсутствует** (проверено 23.08.2026). Здесь описан только стык:
  что подаём на вход и что принимаем на выходе. Реализация — вне VPS.
- `feeds.txt` читается построчно как `категория|название|url`. Строки с `#` пропускаются.
  Символ `|` внутри URL сломает разбор — при добавлении источника проверять.
- **Российские издания тянем через сервер `crm`** (российский IP): с этого сервера РБК не отвечает вовсе,
  Forbes.ru отдаёт HTML вместо фида. Через `ssh crm` оба отдают нормальный RSS (проверено 23.08.2026:
  РБК 30 записей, Forbes 20). В `feeds.txt` такие строки помечены четвёртым полем `crm`.
- Код Дурова (404) и Хайтек+ (500) сломаны на своей стороне — это не блокировка, `crm` их не чинит.
  Остаются через Google News по `site:`.
- Reddit отвечает 429 при залповых запросах — сборщик его теряет примерно через раз, это не поломка.
- Вызовы модели идут только через `llm.py` с `--setting-sources ''`: иначе прогон тянет CLAUDE.md,
  хуки и скиллы штаба — чужой контекст и лишний расход подписки.
- Скоринг заголовков — haiku, отбор и абзацы — sonnet. Держать так: замена haiku на sonnet
  в скоринге умножает стоимость ежедневного прогона без выигрыша в качестве.

## Как собирается лист
`bash scripts/morning.sh` — четыре ступени, каждая пишет свой файл, каждую можно перезапустить отдельно:

1. **collect** — 40 источников за ~7 секунд, окно 30 часов, дедуп по заголовку и ссылке. Российские
   издания идут через `ssh -n crm`. Даёт ~750 кандидатов.
2. **select** — три ступени по cost-curve: питоновский фильтр мусора ($0) → haiku скорит заголовки
   пачками по 50 параллельно → sonnet выбирает финальную десятку с балансом рубрик.
   Правила отбора читаются ИЗ `brand/VOICE.md` и `feed/TASTE.md` — калибровка вкуса меняет
   поведение автоматики без правки кода.
3. **extract** — скачивает каждую отобранную публикацию и просит sonnet собрать карточку СТРОГО
   из текста статьи. Это железное правило голоса, а не пожелание: домысел в листе = ложь в эфире.
4. **render** — `feed/digest/<дата>.json` + `template.html` → фрагмент под артефакт и
   самодостаточный файл для телефона. Затем отправка в Telegram.

Повторный запуск в тот же день ничего не пересобирает — нужен `--force`. `--no-send` собирает без отправки.

## Крон
`30 3 * * *` и страховка `15 5 * * *` — **время в UTC**, сервер живёт по UTC: это 6:30 и 8:15 МСК.
`morning.sh` сам экспортирует PATH: у крона в нём нет `~/.local/bin`, и без этого `claude`
не находится — прогон падает на отборе. При любом сбое скрипт пишет в Telegram сам.

## Откуда берётся текст статьи (порядок, `net.py` + `extract.py`)
1. **Из самого фида.** 156 новостей из 1328 несут полный текст внутри RSS — все РБК и Forbes.ru
   в их числе. Для них веб вообще не нужен, и это единственный способ их прочитать:
   rbc.ru отдаёт curl пустую страницу даже с российского адреса.
2. **Из веба по двум выходам.** Издания режут доступ в обе стороны: РБК и Forbes не отвечают
   отсюда, Reddit отдаёт 403 отсюда и 200 с `crm`. `net.py` пробует оба маршрута, начиная с
   вероятного по доменной зоне (`.ru/.рф/.su/.by/.kz` → сначала `crm`).
3. **Не открылось с обоих — новость выпадает**, её место занимает резерв. Bloomberg закрыт
   с обеих точек: это антибот, а не география, вторым выходом такое не лечится.

## Грабли тракта (проверено 23–25.08.2026 на живых прогонах)
- **Крон-задача, проверенная через `bash -lc`, ничего не доказывает** — `-l` подтягивает профиль,
  крон его не читает. Проверять только `env -i HOME=... PATH=/usr/bin:/bin /bin/bash script.sh`.
  Цена ошибки: 24 и 25 августа лист не пришёл вовсе, и никто об этом не узнал.
- **Часть публикаций не открывается** (Bloomberg 403, Reddit 403, платные стены) — поэтому
  `select.py` кладёт в файл резерв сверх десятки, а `extract.py` добирает из него волнами.
  Без резерва лист выходил на семь новостей.
- **Пул на финальный отбор собирается двумя корзинами** (кейсы + прочее). Простая сортировка
  «кейсы вперёд» приводит к выпуску целиком про ИИ: в финал не попадает ничего другого.
- **Рубрику даёт `extract.py` по тексту статьи, а не `select.py` по списку**: в списке модель
  путает строки и вешает на новость чужую рубрику.
- Браузер при неудачном развороте ссылки отдаёт `chrome-error://…` — адрес принимается только
  если начинается с `http`.
- **Ссылки Google News ведут на переходник, а не на статью.** Ни curl, ни декодирование base64
  адреса не достают — внутри JS-переход. `unwrap.py` открывает их браузером; без этого шесть
  новостей из десяти теряются на извлечении.
- **Модель кладёт перевод строки внутрь JSON-строки** — разбор падает, карточка пропадает.
  `llm._mend` склеивает такие строки перед повторной попыткой; ретрая самого вызова мало,
  модель повторяет ту же ошибку.
- **`--tag -auto` argparse читает как флаг.** Только `--tag=-auto`.
- `pgrep -f "extract.py"` в ожидающем цикле ловит сам себя — цикл не выходит никогда.
